# ПРМ — Корпоративный мессенджер

Корпоративный мессенджер и соцсеть для отдела дополнительного обслуживания аэропорта Пулково.

## Возможности

### Мессенджер (Telegram-like)
- Приватные чаты и групповые чаты
- Обмен файлами (документы, фото, видео)
- Ответы на сообщения
- Индикаторы онлайн/оффлайн статуса
- Индикатор «печатает...»
- Отметки о прочтении
- WebSocket для реального времени

### Блог / Соцсеть
- Создание постов с текстом, фото и видео
- Лайки и комментарии
- Лента новостей
- Профиль пользователя с постами

### Админ-панель
- Управление сотрудниками (создание, удаление)
- Назначение наставников с уведомлением
- Загрузка рабочих документов
- Создание тестов (вручную или с помощью ИИ)
- Назначение тестов конкретным сотрудникам
- Создание и назначение обучений
- Уведомления сотрудников о событиях

### ИИ-функции (Ollama + Qdrant)
- Автоматическая генерация тестов из рабочих документов
- ИИ-ассистент для ответов по рабочим документам
- Семантический поиск по документам (Qdrant)
- Индексация документов в векторную базу

## Запуск

### Предварительные требования
- Node.js 18+
- Ollama (для ИИ-функций)
- Qdrant (для семантического поиска)

### Установка
```bash
npm install
cd client && npm install && cd ..
```

### Разработка
```bash
npm run dev
```
Сервер: http://localhost:3001
Клиент: http://localhost:5173

### Продакшен
```bash
npm run build
npm start
```

### Переменные окружения
```
PORT=3001
JWT_SECRET=your-secret-key
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3
OLLAMA_EMBED_MODEL=nomic-embed-text
QDRANT_URL=http://localhost:6333
```
