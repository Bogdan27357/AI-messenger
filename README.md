# MAS AI System — Мультиагентная система на базе ИИ

Полностью локальная (on-premise) мультиагентная система автоматизации бизнес-процессов с использованием LLM (Ollama) и векторной БД (Qdrant).

## Агенты

| Агент | Назначение |
|-------|-----------|
| **Категоризатор** | Категоризация закупок ТМЦ, подбор поставщиков, автоматическая рассылка и обработка КП |
| **Юрист** | Юридическая экспертиза договоров, RAG по нормативной базе, проверка контрагентов |
| **Командировки** | Учёт командировочных расходов: квитанции → заявки 1С → ЮЗЭДО |

## Технологический стек

- **LLM**: Ollama (qwen2.5, llama3, nomic-embed-text)
- **Векторная БД**: Qdrant
- **Backend**: Python 3.11+, FastAPI, Celery
- **БД**: PostgreSQL 16
- **Очередь**: RabbitMQ + Redis
- **Хранилище**: MinIO (S3-совместимое)
- **OCR**: Tesseract + Ollama Vision
- **Мониторинг**: Prometheus + Grafana

## Быстрый старт

### 1. Клонирование и настройка

```bash
git clone <repo-url>
cd AI-messenger
cp .env.example .env
# Отредактируйте .env, указав реальные параметры подключения
```

### 2. Запуск инфраструктуры

```bash
docker compose up -d
```

### 3. Загрузка моделей Ollama

```bash
./scripts/setup_ollama.sh
```

### 4. Инициализация Qdrant

```bash
python scripts/init_qdrant.py
```

### 5. Запуск приложения (без Docker)

```bash
pip install -e ".[dev]"
uvicorn src.api.main:app --host 0.0.0.0 --port 8000 --reload
```

## API

После запуска доступен Swagger UI: `http://localhost:8000/docs`

### Основные эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/health` | Проверка здоровья системы |
| POST | `/agents/categorizer/bulk-categorize` | Запуск массовой категоризации |
| POST | `/agents/categorizer/process-request` | Обработка заявки на закупку |
| POST | `/agents/legal/analyze` | Анализ договора |
| POST | `/agents/legal/check-counterparty` | Проверка контрагента |
| POST | `/agents/travel/download-receipts` | Скачивание квитанций |
| POST | `/agents/travel/create-request/{trip_id}` | Создание заявки в 1С |
| GET | `/tasks/{task_id}` | Статус задачи |

## Безопасность

- Все данные остаются внутри корпоративного периметра
- Никакие данные не передаются во внешние облачные LLM-сервисы
- TLS 1.2+ для всех соединений
- Ролевая модель доступа (SSO/LDAP)
- Полный аудит действий агентов
